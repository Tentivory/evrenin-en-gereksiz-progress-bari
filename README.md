# Evrenin En Gereksiz Progress Bar'ı

Bu repository, insanlığın en büyük sorunlarından birine çözüm üretmek amacıyla oluşturulmuştur: **Beklemek.**

## Ne Yapar?

`gereksiz_progress.py` dosyasını çalıştırdığınızda, ekranınızda %100'den %0'a doğru giden son derece profesyonel bir ilerleme çubuğu görürsünüz. Her adımda "bu işlem çok kritiktir" diye uyarı alırsınız. İşlem bittiğinde ise hiçbir şey olmamıştır. Tam olarak beklediğiniz gibi.

## Neden Bu Kadar Ciddi?

Çünkü modern yazılım dünyasında progress bar'ların %90'ı zaten sahte. Biz sadece bunu açıkça kabul ediyoruz. Diğerleri de bir gün kabul edecek.

## Kurulum

```bash
python gereksiz_progress.py
```

Başka hiçbir şeye ihtiyacınız yok. İnternet bağlantısı bile şart değil. Evren zaten yavaş.
